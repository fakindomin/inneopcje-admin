# Workflow

- Before writing any code for a problem/question raised in discussion, first explain the diagnosis and the proposed fix, and wait for explicit approval. Don't jump straight to implementing.
- Once a fix is approved and implemented (built/tested and looks right), merge it to `main` right away — don't leave it sitting in an open PR waiting for a separate "scal" go-ahead. The user wants to see effects live on the site as soon as they're ready, not after an extra approval round-trip.
